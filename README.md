# Astrology Form

A simple beginner JavaScript project that generates a fun astrology-style reading based on your date of birth.

## Features
- Enter name and date of birth
- Calculate zodiac sign
- Generate random compliments
- Generate humorous fortunes
- Get a daily recommendation
- Responsive design

## Technologies Used
- HTML
- CSS
- JavaScript

## Live Demo
[View Live Website](https://astrology-formm.netlify.app)

## Run Locally
Download or clone the repository and open `index.html` in your browser.
